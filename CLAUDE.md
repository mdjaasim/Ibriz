# Ibriz

Gold-rate app for Tamil Nadu (PWA, free stack). Read these before working:

- `ibriz-rate-engine/CLAUDE.md` – project rules, constraints and how to explain things to the owner.
- `ibriz-rate-engine/docs/PLAN.md` – the plan, decisions, status and next steps.
- `design/DESIGN.md` – the approved app design (21 Nov 2026). Build exactly what it shows; screens are in `design/screens/` (PNG) and `design/prototype/` (clickable HTML, open `index.html`). Tokens: `design/tokens.css`.

Repo layout: `ibriz-rate-engine/` is the Cloudflare Worker that fetches and serves rates. The PWA has not been started yet; create it in its own folder (for example `app/`) when the build begins.
